# ip-01-p5-works · 创意代码的基本原理

《互动编程》作业一 · 刘晓茹 · 数字媒体艺术

两个用 **p5.js** 写的构成练习，一个静、一个动。打开网址就能直接看，不需要下载任何东西。

在线地址：https://liu123915.github.io/ip-01-p5-works/

## 作品一：几何构成（静态）

- 地址：`/static.html`
- 规则：**不写 `draw()` 循环**，所有图形在 `setup()` 里一次性画完
- 做法：把画布切成四条竖向色带当骨架，再用两个 `for` 循环生成「渐大渐低」的圆，最后叠压几层大圆制造前后层次
- 配色：5 个颜色，米白 `#F2EAD2` / 墨黑 `#141416` / 灰蓝 `#6088A8` / 橘红 `#E84A16` / 明黄 `#F6BC48`

## 作品二：运动轨迹（交互动态）

- 地址：`/dynamic.html`
- 规则：有 `draw()` 循环，至少 2 种交互（这里做了 4 种）

| 操作 | 效果 |
| --- | --- |
| 鼠标 / 手指移动 | 牵引粒子（吸引模式拉近，排斥模式推开） |
| 点击 / 轻触 | 从指尖爆发一圈新粒子 |
| 空格键 | 切换「吸引 / 排斥」 |
| R 键 | 清空重来 |

- 做法：粒子每帧记录位置形成轨迹队列，画面上再盖一层 12% 不透明度的底色，旧轨迹慢慢变暗，于是有了余晖般的拖尾
- 配色：与作品一完全相同，保证两次作业是一套视觉语言

## 目录结构

```
ip-01-p5-works/
├── index.html      索引页（两个作品的入口）
├── static.html     作品一页面
├── static.js       作品一逻辑（无 draw 循环）
├── dynamic.html    作品二页面
├── dynamic.js      作品二逻辑（draw 循环 + 4 种交互）
├── style.css       公共样式（去滚动条、画布居中）
└── lib/p5.js       p5.js 2.3.1 本体
```

## 本地运行

双击 `index.html` 即可，不需要装环境、不需要联网。

## 关于 p5.js 为什么放在本地

原本用的是 jsDelivr CDN 链接，但国内网络访问 CDN 经常卡住或直接超时，页面会一直白屏。改成仓库里的 `lib/p5.js` 后，任何网络环境都能秒开。
